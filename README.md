# 🐧 桌面宠物桌宠（Python）v8

一个用 Python 写的桌面宠物，透明无边框、能走路、能互动、有音效、有天气联动、有昼夜作息、有成就、能换肤、能聊天、会日记、**会躲猫猫**，而且 **会自己找乐子**。

## v8 新增自主行为
- 🎵 **无聊自己唱歌**：空闲久了自动唱歌（气泡+音效，开语音会真唱）
- ⚽ **自己玩小球**：自动滚出红球追着踢，带重力弹跳
- 💻 **自己玩电脑**：自动掏出小屏幕摸鱼（看视频/刷动态/回消息）
- 🎶 **自己点歌听**：自动切到听歌状态，播放 songs/ 里的歌或 BGM
- 🐧 **自己召唤同伴**：无聊时自己叫同伴出来玩（临时，不写盘）
- 💾 **手动添加的同伴不持久**：右键"召唤同伴"加的，下次启动自动消失（只有存档里的那只常驻）

## v8.1 修正 / 增强
- 🔍 **消失也能点出来**：双击屏幕任意位置直接把躲起来的它揪出来，不再要求点准角落；右键也有「🔍 把它找出来」
- 🎤 **唱歌自己搜歌词**：唱歌时自动联网搜一段真实歌词气泡展示，搜不到才用内置歌词

## 功能总览
- 🐾 透明桌宠，自动散步/发呆/睡觉
- 🖱️ 拖拽、单击聊天、双击找躲起来的它、右键菜单
- 🔊 音效（自动生成 beep，可换真实 wav）
- 🗣️ 语音播报（可选，pyttsx3）
- 🌤️ 天气联动（下雨☂️/下雪❄️/晴天🕶️）
- 🌙 昼夜作息（半夜自动睡觉 + 写日记）
- 🎵 背景音乐 / 点歌（songs/ 目录）
- 🏆 成就系统（16 个）
- 🎨 换肤（企鹅/猫/狗/恐龙）
- 🐾 鼠标跟随、👣 脚印拖尾
- 💬 记忆对话、📓 心情日记、🔔 通知联动
- 🙈🔍 躲猫猫
- ⚙️ 设置（含"自主行为"总开关）、💾 自动存档、🚀 开机自启

## 安装
```bash
pip install -r requirements.txt
python pet.py
```

## 换素材
- 帧图：`frames/{skin}_{state}_{i}.png`
- 音效：`sounds/step.wav` `eat.wav` `poke.wav` `scare.wav` `sleep.wav` `talk.wav` `sad.wav` `notify.wav`
- 歌曲：`sounds/songs/*.mp3`（它自己听歌会随机播这些）

## 操作
- 拖动：移动
- 双击空白：找躲起来的它
- 单击它：聊天
- 右键：喂食/逗弄/聊天/躲起来/找出来/唱歌/玩球/玩电脑/听歌/小游戏/睡觉/跟随/召唤同伴/换肤/日记/设置/成就/退出

## 打包
```bash
build.bat
```
